# Instructions for any AI working on this repository

This website (clclegal.in, Choudhary Law Chambers) is maintained by two AI assistants (ChatGPT/Codex and Claude) for the owner, Pankaj Kumar Choudhary.

Before doing anything:
1. Read `docs/AI-WORKLOG.md` in full.
2. Work from the latest `main` branch.
3. Do not edit files listed under "In progress" by the other AI.
4. Stay in your own area as listed under "Who owns what".

When finished:
1. Open a pull request. Never push to `main`. Never merge.
2. In the same pull request, update `docs/AI-WORKLOG.md`: add or move your task to "Done" with the PR number.

Legal content: no superlatives or promises (Bar Council of India Rule 36). Flag anything the owner must verify.
